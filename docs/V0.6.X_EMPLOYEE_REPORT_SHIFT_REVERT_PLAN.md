## 1. Executive Summary

The client requests partial reversion of shift-based reporting (introduced in v0.5.9) from the **Employee Monthly Report** only. The shift feature itself remains in the database and reporting panel — only the employee report view and exports are affected.

**Key changes required:**
- Remove shift dimension from employee report (single row per employee, no "Zmiana" column)
- Restore `sumaBezNadgodzin` to include **paid absences** (UW, L4, UOK, UŻ, etc.) as "normative/paid hours"
- Keep NN (unpaid absence) excluded from all paid-hour totals
- Preserve all unrelated fixes from v0.6.0/v0.6.1 (NN handling, closure control, etc.)
- **Remove "Łącznie przepracowane w okresie" column** — it was introduced to sum across shift rows; with single row per employee it duplicates "Suma godzin z nadgodzinami"

## 3. Current Employee-Report Architecture

### 3.1 Backend: `getEmployeeReportRows()` (`backend/src/routes/analytics.ts:288-377`)

**Input:** `EmployeeReportFilters { dateFrom?, dateTo?, employeeId? }`  
**Output:** `EmployeeReportRow[]` — one row per **employee × shift**

```typescript
export type ShiftDimension = 'FIRST' | 'SECOND' | 'THIRD' | 'UNSPECIFIED' | 'ABSENCE';

export type EmployeeReportRow = {
  employeeId: string;
  employeeName: string;
  workShift: ShiftDimension;        // ← shift dimension
  workShiftLabel: string;           // ← "I", "II", "III", "Brak danych", "Nie dotyczy"
  suma: number;                     // worked hours WITH overtime
  sumaBezNadgodzin: number;         // worked hours WITHOUT overtime (NO absences)
  [workTimeTypeCode: string]: number; // dynamic columns per work time type
};
```

**Aggregation logic (lines 304-360):**
- Groups by `employeeId` + `shiftKey` (derived from `workShift` + `isAbsence`)
- Absences → `shiftKey = 'ABSENCE'` (label "Nie dotyczy")
- Work entries without shift → `shiftKey = 'UNSPECIFIED'` (label "Brak danych")
- `suma` += hours for non-absence entries
- `sumaBezNadgodzin` += hours for non-absence, non-overtime entries
- Absence hours go only into dynamic columns (e.g., `UW: 8`), **not** into `suma`/`sumaBezNadgodzin`

### 3.2 Frontend: `ReportsView.tsx` (lines 787-837)

**Table columns:**
1. Pracownik
2. Łącznie przepracowane w okresie (monthly total, rowSpan per employee)
3. **Zmiana** (shift label: I/II/III/Brak danych/Nie dotyczy)
4. Suma godzin z nadgodzinami
5. Suma godzin bez nadgodzin
6. Dynamic columns per work time type (G, NDR, NS, UW, UOK, UŻ, L4, ...)

**Export (XLSX/CSV):** Same column structure (`backend/src/routes/analytics.ts:1195-1260`)

### 3.3 Work Time Types (from `backend/prisma/seed.ts:56-64`)

| Code | Name | requiresOrder | isAbsence | Category |
|------|------|---------------|-----------|----------|
| G | Standardowe godziny pracy | true | false | **Normative work** |
| NDR | Nadgodziny | true | false | **Overtime** |
| NS | Nadgodziny sobota/niedziela | true | false | **Overtime** |
| UW | Urlop wypoczynkowy | false | true | **Paid absence** |
| UOK | Urlop okolicznościowy | false | true | **Paid absence** |
| UŻ | Urlop na żądanie | false | true | **Paid absence** |
| L4 | Zwolnienie chorobowe | false | true | **Paid absence** |
| WKU | Służba wojskowa | false | true | Paid absence (custom) |
| NN | Nieobecność nieusprawiedliwiona | false | true/false* | **Unpaid absence** |

*NN may have legacy `isAbsence=false` but is treated as absence via `isReportingAbsence()` helper (v0.6.1).

## 5. Current Calculation Semantics

| Metric | Current Formula | Includes |
|--------|-----------------|----------|
| `suma` | Σ hours where `!isAbsence` | G, NDR, NS, NOC, other work types |
| `sumaBezNadgodzin` | Σ hours where `!isAbsence && !isOvertime` | G, NOC, other non-overtime work |
| Dynamic columns (UW, L4, etc.) | Σ hours per code | All entries for that code |
| `NN` column | Σ hours for NN | NN entries only |
| Monthly total (frontend) | Σ `row.suma` per employee | Same as `suma` sum |

**Overtime detection (line 348-352):**
```typescript
const isOvertime = OVERTIME_CODES.includes(code) ||
  code.startsWith('ND') ||
  code.startsWith('NS') ||
  (report.workTimeType?.name?.toLowerCase().includes('nadgodzin') ?? false);
```

## 6. Client-Required Calculation Semantics

| Metric | Required Formula | Includes |
|--------|------------------|----------|
| `suma` (Suma godzin z nadgodzinami) | Σ hours where `!isAbsence` | **Unchanged** — worked hours with overtime |
| `sumaBezNadgodzin` (Suma godzin bez nadgodzin) | Σ hours where `(!isAbsence && !isOvertime) || (isPaidAbsence)` | **Normative work + paid absences** (UW, L4, UOK, UŻ, WKU, etc.) |
| Dynamic columns | Unchanged | All entries per code |
| `NN` column | Unchanged (visible, excluded from totals) | NN entries only |

**Paid absence definition:** Any work time type where `isAbsence === true` **AND** code ≠ `NN`.  
Do NOT hard-code codes — use the `isAbsence` flag + `UNPAID_ABSENCE_CODE` constant.

**Unpaid absence:** `NN` (code constant `UNPAID_ABSENCE_CODE = 'NN'`). May have legacy `isAbsence=false` but is classified as absence via `isReportingAbsence()`.
