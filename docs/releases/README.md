# Release Archive — docs/releases/

Archiwum historycznych raportów wersyjnych (release / review / audit / rework / signoff / validation).

Zasady:
* `ROOT` repozytorium = wyłącznie aktywna dokumentacja projektu (`README.md`, `CHANGELOG.md`, `PROJECT_STATUS.md`, `AGENTS.md`, `DEPLOYMENT.md`).
* `docs/releases/vX.Y.Z/` = dowody audytowe i raporty konkretnej wersji.
* Raportów historycznych nie wolno usuwać ani modyfikować ich treści.
* Nowe raporty wersyjne twórz bezpośrednio w `docs/releases/vX.Y.Z/` (patrz `docs/playbooks/RELEASE.md`, sekcja „Lokalizacja raportów wersji").
