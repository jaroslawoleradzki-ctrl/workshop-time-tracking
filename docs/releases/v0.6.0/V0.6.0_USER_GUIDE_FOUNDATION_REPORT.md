## Implemented foundation

- `HelpView` is available through the `help` tab for Administrator and Leader roles.
- Help uses valid `#help/<chapter-id>` deep links, desktop chapter navigation, responsive horizontal navigation, role badges, application version header, and previous/next navigation. Selecting a normal tab removes the Help hash and preserves normal tab restoration.
- Typed TSX chapters currently cover `pierwsze-kroki` and `logowanie`.
- The manifest-driven Playwright pipeline is in `frontend/docs-screenshots/`. Help chapters reference stable screenshot IDs; the manifest supplies filenames and captions. Browser-free validation compares chapters, manifest entries, and PNG files.
- The generated asset is `frontend/public/help/logowanie-01-ekran-logowania.png`.
- `backend/prisma/docs-db-guard.ts` rejects every URL whose database name does not end in `_docs` before a Prisma client is created; `seed:docs` uses the guard. The docs seed uses fixed IDs, dates, timestamps, and a fictional credential hash.
