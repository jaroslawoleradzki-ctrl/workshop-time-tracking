## Release scope

v0.6.0 adds the integrated **Pomoc / Instrukcja** guide to the existing tab and hash navigation. Administrators and Leaders can open it from the application navigation and header. It contains all 15 approved chapters and the application version header, without adding a router.

The guide documents application navigation, login, work-time entry, required I/II/III shifts, absence handling and ranges, copy-day behavior, orders, HR and by-order reporting, absence periods, reconciliation totals, exports, company calendar, dictionaries, imports, dashboard, administration, and common situations. The HR report continues to use one `Zmiana` column.

The manifest references 21 Playwright-generated screenshots from the real application. They cover the approved desktop scenarios and the two tablet views. Five contextual Help actions open the relevant Reporting, HR report, by-order report, Orders, and Company Calendar chapters. Desktop and tablet Help layouts were exercised in the browser.

The documentation fixture is guarded to database names ending in `_docs`. Two fresh isolated docs databases produced identical snapshots after migration and seed; reseeding preserved the snapshot. No development, demo, client, or production data was used to generate guide screenshots.
