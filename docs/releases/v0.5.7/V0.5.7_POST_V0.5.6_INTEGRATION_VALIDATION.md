## Compatibility verification

### v0.5.7 cumulative order progress

`getOrderReportRows()` fetches non-deleted reports only through the selected `dateTo`. It calculates:

- `actualHours` from entries in the selected period only;
- `deviation` and `percent` from entries at/after normalized `orderDate` through `dateTo`;
- zero-plan percent as `0`;
- two-decimal output values.

The original regression test still exists: `keeps period hours while calculating order progress cumulatively through the report end`. It verifies plan 100h, July 30h, August 20h, future September 10h, and a soft-deleted 8h report. For August it asserts `actualHours = 20`, `deviation = 50`, and `percent = 50`; it also covers CLOSED, SUSPENDED, zero-plan, `onlyWithHours`, XLSX, and closure-report behavior.

### v0.5.6 historical reconciliation stability

The integrated `getOrderReportRows()` closure predicate has all three branches:

1. current OPEN orders;
2. CLOSED orders with `completionDate` in the period;
3. OPEN/CLOSED orders having a non-deleted related report in the requested period.

`getReconciliationDiagnostics()` has the matching third branch. Therefore, an order closed later cannot remove legitimate historical in-period work from the closure report/control reconciliation. `SUSPENDED` and soft-deleted orders/reports remain excluded according to the existing rules.

### Combined regression coverage

One minimal new test was added:

`keeps cumulative progress for a later-closed order included by historical closure stability`

It requires the third Prisma closure predicate before returning the row, then uses July 30h, August 20h, future September 10h, and soft-deleted August 8h for a CLOSED order completed after the August report period. It proves the combined result is visible in closure mode and remains `actualHours = 20`, `deviation = 50`, `percent = 50`. It fails if the v0.5.6 historical predicate is removed or if future/deleted work contaminates the cumulative calculation.

Existing v0.5.6 regression tests independently continue to prove the matching reconciliation/control-summary predicate, including the 35-hour later-closed order and its no-in-range-hours contrast.
