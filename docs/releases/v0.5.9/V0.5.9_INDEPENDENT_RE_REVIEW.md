## BACK-001 and atomicity verification

The implementation validates `sourceReports` before persistence:

```ts
const invalidShiftReport = sourceReports.find((report) => {
  const type = typesByCode.get(report.workTimeTypeCode);
  const isAbsence = type?.isAbsence ?? false;
  return !isAbsence && (!report.workShift || !['FIRST', 'SECOND'].includes(report.workShift));
});

if (invalidShiftReport) throw new CopyLastDayError(400, 'WORK_SHIFT_REQUIRED', ...);
```

This validation occurs before `createMany`, inside the existing transaction. Thus no destination write has occurred when a null/invalid worked source is rejected. The mixed-source regression test directly queries the fake destination state and asserts zero rows, then asserts the FIRST and null source records remain unchanged. It is therefore evidence of both control flow and the required all-or-nothing state.
