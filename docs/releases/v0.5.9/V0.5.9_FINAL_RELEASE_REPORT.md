## Release Functionality

- **Work Shifts**: Support for 3 distinct shifts: `I` (`FIRST`), `II` (`SECOND`), and `III` (`THIRD`).
- **Absence Constraints**: Absence records (`isAbsence === true`) enforce `workShift = null`, disable shift selection in UI (`Nie dotyczy (nieobecność)`), and clear any pre-selected shift when toggled. Switching back to worked time requires an explicit shift selection.
- **Copy Last Day**: Preserves `FIRST`, `SECOND`, `THIRD`; copies absences with `workShift = null`; atomically rejects historical worked entries without shift (`WORK_SHIFT_REQUIRED`) with zero destination row creation.
- **HR Monthly Report & Exports**:
  - Exactly **one** `Zmiana` column in table, XLSX, and CSV (replacing separate shift columns).
  - Row granularity per employee + shift dimension (`I`, `II`, `III`, `Brak danych` for historical null, `Nie dotyczy` for absence).
  - Absence hours and overtime are not duplicated across shift rows.
  - Closure control reconciliation (`getClosureControlSummary`) remains mathematically invariant and matched (`status: MATCHED`).
- **Compatibility & Regressions**:
  - v0.5.6 historical reconciliation preserved.
  - v0.5.7 cumulative order progress preserved.
  - v0.5.8 calendar-aware default work type preserved.
  - art. 188 KP (OP) absence handling preserved.
